# Immich

[Immich](https://immich.app/) is a photo and video management solution.

## Additional setup

### Environment variables

Create `.env` with the following variables

Details for variables provided by Immich can be found [here](https://docs.immich.app/install/environment-variables/)

```
# Provided by Immich
DB_DATABASE_NAME
DB_DATA_LOCATION
DB_PASSWORD
DB_USERNAME
IMMICH_VERSION
TZ

# Added by me
HDD_PATH
SSD_PATH
```
