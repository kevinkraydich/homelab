# Homelab

My home lab setup

## Services

All services run via Docker compose

| Service | Description |
| ------- | ----------- |
| [\*arr stack](/arr) | Content management and indexing |
| [Audiobookshelf](/audiobookshelf) | Audiobook and podcast streaming |
| [Beszel](/beszel) | Performance monitoring |
| [Caddy](/caddy) | Reverse proxies |
| [Gluetun and qBitTorrent](/torrent) | Torrenting |
| [Home Assistant](/homeassistant) | Home automation |
| [Immich](/immich) | Photo and video management |
| [Jellyfin](/jellyfin) | Media streaming |
| [Pi-Hole](/pihole) | Ad blocker |
| [Seerr](/seerr) | Media request management |
| [WireGuard](/wireguard) | VPN |
